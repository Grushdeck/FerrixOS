Ferrix OS — это полноценная ОС для IBM PC/AT, написанная на чистом ассемблере NASM. Ядро размером всего 31.7 КБ грузится с дискеты или USB, работает на 8086/286+ и управляет VGA, FAT12/FAT16, PS/2-мышью и звуком напрямую — без единого байта лишнего кода.

Возможности

Всё — от загрузчика до синтезатора

Ferrix OS не прячет железо за абстракциями: каждая подсистема написана вручную и доступна программам через единый интерфейс FAPI.

Ядро · KERNEL.SYS1000:0000

31.7 КБ чистого real mode

Единый бинарник на NASM (org 0, DS=ES=SS=CS=1000h): драйвер FAT12/FAT16 с кэшем 1 КБ, быстрый телетайп в B800:0000, PS/2-мышь, Sound Blaster 16 и Intel HD Audio, диспетчер int 80h. Загрузка — с 1.44 МБ дискеты или 32 МБ MBR/FAT16 диска.

8086/286+FAT12 / FAT16 r/wVGA 80×25PS/2 mouse

SB16 и Intel HD Audio

Плеер play потоково читает WAV блоками по 32 КБ. HDA работает через PCI и Unreal Mode с ресэмплером 48 кГц — до ~50 минут музыки на диске 32 МБ.

Скриншоты

Настоящий VGA, без эмуляции

Официальные скриншоты из репозитория: рабочий стол gui, синтезатор, игры и часы. Нажмите на карточку, чтобы увеличить.

$ gui

Рабочий стол GUI

Три окна одновременно — файловый менеджер FM, игра 2048 и аналоговые часы CLOCK — поверх фирменного дithered-фонa. Каждое окно живёт в собственном 64-КБ сегменте.

$ synth

SYNTH.FAP

8-голосный синтезатор на 24 кГц: две октавы ASCII-клавиатуры, ADSR-пресеты и фирменное эхо 341 мс.

$ mines

Сапёр

Классический Minesweeper с управлением мышью и сохранением рекордов в файл .HI на диске.

$ 2048

2048

Головоломка 2048 в текстовом VGA-режиме: цифры, цвета и таблица рекордов — всё на чистом int 80h.

$ clock

CLOCK.FAP

Полноэкранные аналоговые часы со стрелками, крупными цифрами HH:MM:SS и датой с учётом часового пояса.

$ pong

Pong

Аркадный Pong из набора игр на базе библиотеки game.inc — вместе со snake и tetris.

Интерактив

SYNTH.FAP — прямо в браузере

Веб-версия настоящего синтезатора Ferrix OS: 8 голосов, 4 формы волны, ADSR-пресеты и то самое эхо 341 мс. Играйте мышью или клавишами Z–/ и Q–P.

SYNTH.FAP — 8-voice polyphonic synth · 24 kHz · Intel HDA

Клавиши: нижний ряд Z X C V B N M , . / · верхний ряд Q W E R T Y U I O P · чёрные — цифры и S D G H J L ;. Звук синтезируется через Web Audio API.

Разработка

ferpy → frasm → IRON.FAP

Пишите на Python-подобном синтаксисе, компилируйте в нативный 16-битный код и собирайте прямо внутри Ferrix OS. Интерфейс программ — 38 вызовов int 80h.


          

            hello.fpy→tools/fpy.py→HELLO.ASM→iron→HELLO.FAP

          Запуск
          
Соберите и запустите за минуту

          
Скачайте готовый образ или соберите Ferrix OS скриптом build-img.sh (нужны nasm, dosfstools, mtools и qemu) — он сам соберёт ядро, программы, образ диска и запустит QEMU.

        

      

      

        

          

            
QEMU · готовый образ

            
unzip ferrix-img.zip
qemu-system-i386 -drive file=ferrix.img,format=raw,if=ide -boot c \
  -device sb16 -device intel-hda -device hda-output

          

          

            
Сборка из исходников (build-img.sh)

            
git clone https://github.com/Grushdeck/FerrixOS
cd FerrixOS
./build-img.sh            # соберёт ferrix.img и запустит QEMU
./build-img.sh floppy     # дискета 1.44 МБ (os.img)
NORUN=1 ./build-img.sh    # только собрать, без запуска

          

          

            
Первая программа на ferpy

            
python3 tools/fpy.py examples/hello.fpy -o HELLO.ASM
# внутри Ferrix OS:
# neo@ferrix ~ » iron /HELLO.ASM /HELLO.FAP

Один ZIP-файл (~206 КБ) с гибридным образом: дискета 1.44 МБ, MBR/FAT16 диск 32 МБ для USB и El Torito ISO для CD.
