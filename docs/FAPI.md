# Внешние программы (.FAP) и системные вызовы FAPI

Формат **FAPI** (Ferrix App Image) — плоский образ, похожий на `.COM`:

```
0000h  dw версия API ядра (3)        0080h  аргументы командной строки (ASCIIZ)
0100h  "FAPI", db 1, db 0, dw entry, 8 байт резерва   — заголовок (макрос FAPI_HEADER)
0110h  код программы
```

При входе `CS=DS=ES=SS=4000h`, `SP=FFFEh`, `DS:SI` → аргументы. Программе доступен весь сегмент
(64 КБ) и видеопамять напрямую. Выход — `FAPI_QUIT` (`int 80h`, `AH=0`) или `retf`.

Системные вызовы `int 80h` (`AH` = функция, см. `fapi.inc`):

| AH | Функция | Регистры |
|----|---------|----------|
| 00 | exit | — |
| 01 | putc | AL = символ |
| 02 | puts | DS:SI = ASCIIZ; байт `1` + атрибут внутри строки переключает цвет (в конце строки цвет сбрасывается на 07h) |
| 03 | getkey | → AX (AL = ASCII, 0/E0 = расширенная клавиша, AH = скан-код) |
| 04 | keyhit | → AX (0 = нет), ZF |
| 05 | setcursor | DH = строка, DL = столбец |
| 06 | getcursor | → DH, DL |
| 07 | cls | — |
| 08 | readfile | DS:SI путь, ES:DI буфер, CX макс → AX длина; CF=1: AX = 1 нет файла, 2 слишком большой, 3 ошибка диска |
| 09 | writefile | DS:SI путь, ES:DI данные, CX длина → CF=1 ошибка |
| 0A | ticks | → DX:AX (18.2 Гц) |
| 0B | printdec | DX = число |
| 0C | getcwd | ES:DI ← ASCIIZ («/» для корня) |
| 0D | sleep | CX = тиков |
| 0E | uiredraw | очистить экран и нарисовать баннер оболочки |
| 0F | rand | → AX псевдослучайное 16-бит число |
| 10 | cursor | CX = 2000h спрятать курсор, 0607h показать |
| 11 | localtime | → CH час, CL мин, DH сек, DL день месяца (с учётом TZ) |
| 12 | username | ES:DI ← ASCIIZ имя пользователя |
| 13 | beep | короткий сигнал PC-спикером |
| 14 | kbflush | очистить буфер клавиатуры |
| 15 | putat | DH строка, DL столбец, AL символ, BL атрибут (прямо в видеопамять) |
| 16 | fillrect | DH,DL левый верхний угол; CH высота, CL ширина; AL символ, BL атрибут |
| 17 | putsat | DH,DL позиция, DS:SI ASCIIZ, BL атрибут (макрос `FAPI_PUTSAT row,col,str,attr`) |
| 18 | readdir | DS:SI путь («» = текущий), ES:DI буфер, CX макс записей → AX записей (32-байтные записи FAT, без удалённых/LFN/метки) |
| 19 | shell | DS:SI команда оболочки (`mkdir`, `rm`, `cp`, `mv`, `rename`…); вывод с позиции курсора. Запуск .FAP изнутри программы не допускается |
| 1A | exec | DS:SI команда, DL=1 — после неё ждать клавишу. Выполняется **после выхода** программы, затем программа перезапускается с теми же аргументами (так `fm` открывает `mono` и другие .FAP) |
| 1B | stat | DS:SI путь → DX:AX размер, CL атрибут; CF=1 нет |
| 1C | readat | DS:SI путь, ES:DI буфер, BX номер 512-байтного сектора файла, CX макс → AX прочитано (0 = конец). Потоковое чтение файлов любого размера |
| 1D | append | DS:SI путь, ES:DI данные, CX длина — дописать в конец (создаёт файл); CF=1 ошибка |
| 1E | mouse | → CX столбец, DX строка, AL кнопки (bit0 левая, bit1 правая), AH=1 если мышь есть |
| 1F | mouseshow | CL=1 показать текстовый курсор мыши (инверсия знакоместа) / 0 спрятать; при выходе программы прячется |
| 20 | chdir | DS:SI путь → сменить текущий каталог оболочки; CF=1 ошибка |
| 21 | wm | Оконный менеджер (служебная, использует `gui`): AL=0 установить обработчик (DX смещение, CL строк), AL=1 снять, AL=2 загрузить образ DS:SI с аргументами ES:DI в сегмент DX (CX — сегмент виртуального экрана) → AX точка входа; AL=3 — сегмент консольного вывода ядра (CX, 0 = B800h) → AX прежний |
| 22 | audio | PCM-поток через HD Audio . AL=0 открыть: ES:DI буфер из **двух половин** по CX байт, BX формат SDFMT (0110h = 24 кГц/16 бит/моно, 0011h = 48 кГц/16 бит/стерео); контроллер зацикленно играет буфер прямо из памяти программы. AL=1 опрос → AL = играющая половина (0/1), DX позиция; программа дозаписывает **свободную** половину. AL=2 остановить. CF=1 — HDA нет или уже открыт. При выходе программы поток закрывается автоматически |
| 23 | date | → CX год, DH месяц, DL день, AL день недели (0 = воскресенье); с учётом часового пояса, как `date` |
| 24 | sysinfo | AL=0 диск → AX занято КБ, DX всего КБ, CL = 12/16 (тип FAT), CH буква тома; CF=1 ошибка. AL=1 → AL смещение часового пояса в часах (знаковое), AH=1 если RTC идёт по UTC. AL=2 → DX:AX тики таймера на момент загрузки (uptime = `ticks` − это). Используется `FETCH.FAP`, `TIME.FAP` |
| 25 | waitkey | Как `getkey`, но при бездействии запускает заставку ядра (`saver`) — для оболочек (`FSH.FAP`) |

Функции 0F–17 появились в API версии 2, 18–20 — в версии 3, 21–22 — в версии 4 (слово по адресу 0000h). Все вызовы сохраняют регистры,
кроме явно возвращаемых; CF=1 означает ошибку (или неизвестный номер функции).

**Мышь.** Ядро содержит драйвер PS/2-мыши (через BIOS `int 15h`, функция C2h): координаты переводятся в знакоместа
80×25, курсор рисуется инверсией атрибута и не мешает выводу программ (на время каждого системного вызова он
снимается). В QEMU и на реальном железе с PS/2/эмуляцией USB-мыши работает «из коробки»; если мыши нет, `mouse`
возвращает AH=0.

Минимальная программа:

```nasm
%include "fapi.inc"
    FAPI_HEADER
start:
    FAPI_PRINT msg
    FAPI_QUIT
msg db "Hi!", 13,10, 0
```

Сборка: `nasm -f bin -I. -Iapps/ apps/prog.asm -o PROG.FAP` (build-img.sh делает это для всех файлов в `apps/`
и кладёт результат в `/SYSTEM/SYSAPPS/`). Пример с аргументами, клавиатурой и каталогом — `apps/hello.asm`;
полноценные приложения — `apps/fm.asm`, `apps/mono.asm`, `apps/calc.asm`, `apps/paint.asm`.
