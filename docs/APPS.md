# Программы Ferrix OS

Подробное описание программ из `/SYSTEM/SYSAPPS`.

## Стандартный пакет программ (/SYSTEM/SYSAPPS)

| Программа | Назначение |
|-----------|------------|
| `FM.FAP` | Двухпанельный файловый менеджер  |
| `MONO.FAP` | Текстовый редактор (до 58 000 байт) |
| `CALC.FAP` | Калькулятор: `calc 2+3*(4-1)`, экранный калькулятор `calc` (по умолчанию), консольный диалог `calc -c` |
| `GUI.FAP` | Оконный менеджер / рабочий стол |
| `PAINT.FAP` | Рисовалка: холст 80×23 клетки, 16 цветов, сохранение в 8-битный BMP 320×92 (клетка = 4×4 пикселя); такой файл открывается `view` и снова `paint` |
| `SNAKE.FAP`, `TETRIS.FAP`, `MINES.FAP`, `2048.FAP`, `PONG.FAP` | Игры |
| `CLOCK.FAP` | Часы: аналоговый циферблат на весь экран, большие цифровые часы и дата (`clock`, любая клавиша — выход) |
| `FERRAMP.FAP` | Музыкальный проигрыватель WAV  |
| `MICRO.FAP` | Эмулятор CHIP-8  |
| `IRON.FAP` | Компилятор ассемблера frasm → `.FAP`  |
| `SYNTH.FAP` | Синтезатор-пианино с мини-секвенсором на HD Audio  |
| `HELLO.FAP` | Пример |

Все программы пакета сделаны в одном стиле: строка-заголовок, рабочая область, строка клавиш/состояния внизу,
управление клавиатурой и мышью (клик по кнопкам `calc`, рисование в `paint`, панели и клавишная строка `fm`).

**paint:** стрелки + Space / левая кнопка — рисовать текущим цветом, Del / правая кнопка — стирать, `0-9 a-f` или клик
по палитре — цвет, F2 (или S) — сохранить (имя спрашивается, если не задано аргументом), C — очистить, Esc — выход.

## Пакет игр

Запуск: `snake`, `tetris`, `mines`, `2048`, `pong` (`help games`).
Рекорды хранятся в корне диска: `SNAKE.HI`, `TETRIS.HI`, `MINES.HI`, `2048.HI` (обычный текст, можно удалить).

| Игра | Управление |
|------|------------|
| **Snake** — змейка на поле 78×22, с каждыми 5 яблоками ускоряется | стрелки / WASD — направление, P — пауза, Esc — выход, Enter — заново после проигрыша |
| **Tetris** — стакан 10×20, 7 фигур, уровень растёт каждые 10 линий | ← → — сдвиг, ↑ — поворот, ↓ — мягкое падение, Space — сброс, P — пауза, Esc — выход |
| **Mines** — сапёр 16×16, 40 мин, первый ход всегда безопасен | стрелки — курсор, Space/Enter — открыть, F — флаг, N — новая игра, Esc — выход |
| **2048** — поле 4×4, цветные плитки, счёт и рекорд | стрелки / WASD — сдвиг, R — новая игра, Esc — выход |
| **Pong** — против компьютера, до 10 очков; мяч ускоряется, угол отскока зависит от места удара по ракетке | ↑ ↓ или W/S — ракетка, P — пауза, Esc — выход |

Игры используют общий файл `apps/game.inc` (подключается сразу после `FAPI_HEADER`): `g_rand` (CX → AX 0..CX-1),
`g_num_at` (число в позиции с дополнением пробелами), `g_frame` (двойная рамка), `g_wait_key` (ждать клавишу
не дольше CX тиков), `g_hi_load`/`g_hi_save` (рекорд в файле). Он же — удобный шаблон для своих игр.

## Проигрыватель ferramp (apps/ferramp.asm → FERRAMP.FAP)

```
ferramp              список всех WAV и SNG текущего каталога (если пусто — корня)
ferramp SONG.WAV     то же, но сразу играет указанный файл
ferramp DIR/         открыть каталог без автозапуска
```

Экран: заголовок с текущим треком (частота, каналы, длительность), список треков
(имя, размер, время, формат), строка состояния ядра и строка клавиш. Enter/Space —
играть выбранное, N/P — следующий/предыдущий, A — автопереход к следующему треку
(по умолчанию включён; если трек остановили клавишей — автопереход не срабатывает),
R — пересканировать каталог, любая клавиша во время игры — стоп, Esc — выход.
Мышь: клик по строке — выбрать, двойной клик — играть. Сам звук выдаёт ядро
(`play`, Sound Blaster 16 или HD Audio) — проигрыватель остаётся на экране.

Файлы `.SNG` (записи секвенсора `synth`) показываются в списке с пометкой `SNG  synth`
и длительностью по времени последнего события. Ядро не умеет запускать программу из программы,
поэтому для `.SNG` плеер делает `FAPI_EXEC "synth FILE.SNG -p"`: ferramp выходит, synth играет
песню (любая клавиша — стоп) и завершается, после чего ferramp перезапускается в том же каталоге
(в `gui` synth открывается в своём окне). Автопереход после `.SNG` не работает.
## Синтезатор synth (apps/synth.asm + apps/synth_t.inc → SYNTH.FAP)

```
synth                пианино; запись по умолчанию в /SONG.SNG
synth TUNE.SNG       файл для F9 (сохранить) / F10 (загрузить)
synth TUNE.SNG -p    проиграть файл и выйти (так работают `play X.SNG` и ferramp); любая клавиша — стоп
```

Программный синтезатор реального времени: 24 кГц, 16 бит, моно, до **8 голосов** одновременно,
звук идёт через `FAPI_AUDIO` (нужен 386+ и контроллер HD Audio — как для `play ... hda`; в QEMU:
`-device intel-hda -device hda-output`). Программа сама считает сэмплы и заполняет свободную половину
буфера (2 × 1024 сэмпла, задержка ≈ 43 мс). Клавиатура опрашивается прямо с контроллера (перехват IRQ1),
поэтому есть настоящие нажатие/отпускание клавиш — аккорды держатся, пока нажаты.

- **Клавиши-ноты:** нижний ряд `Z S X D C V G B H N J M , L . ; /` — текущая октава (C..E следующей),
  верхний ряд `Q 2 W 3 E R 5 T 6 Y 7 U I 9 O 0 P` — октава выше. На экране — клавиатура 2 октав,
  нажатые клавиши подсвечиваются.
- **F1–F4** волна: синус / прямоугольник / пила / треугольник (таблицы по 256 сэмплов строятся при старте,
  синус — из `synth_t.inc`). **F5/F6** октава −/+ (0..7). **F7** эхо (задержка 341 мс, затухание ½).
  **F8** пресет огибающей ADSR: пианино, орган, пад, щипок (атака/спад/удержание/затухание в сэмплах).
- **Секвенсор:** Space — запись старт/стоп (пишутся события «нота вкл/выкл» с временем в сэмплах, волной и
  пресетом; до 2000 событий), Enter — воспроизвести, Backspace — очистить, F9 — сохранить в `.SNG`,
  F10 — загрузить. В корне образа есть пример `/DEMO.SNG` (гамма; `play /DEMO.SNG`). Формат `.SNG`: 8 байт `FXSNG` + версия + число событий, затем события по 8 байт
  (`dd время, db вид, db нота, db волна, db пресет`).
- Esc — выход (поток останавливается, IRQ1 возвращается ядру).
- Внутри `gui` программа работает в окне (вызов `FAPI_AUDIO` проходит через оконный менеджер в ядро); в паузах
  она вызывает `FAPI_KEYHIT`, поэтому рабочий стол перерисовывается и мышь работает. Но клавиатуру synth держит
  сам (IRQ1): пока он запущен, все клавиши достаются ему, в каком бы окне ни был фокус.
## Эмулятор CHIP-8 micro (apps/micro.asm → MICRO.FAP)

```
micro GAME.CH8 [-s N] [-c X] [-q] [-l] [-w]
   -s N   скорость: команд на тик таймера (18,2 Гц), по умолчанию 40 (~730 команд/с)
   -c X   цвет пикселей — шестнадцатеричная цифра 0-F (по умолчанию A, ярко-зелёный)
   -q     «сдвиговая» особенность: 8xy6/8xyE сдвигают VX, а не VY (нужна части игр)
   -l     Fx55/Fx65 не меняют I (поведение SCHIP)
   -w     спрайты заворачиваются по краям экрана вместо обрезки
```

Полный набор из 35 команд CHIP-8 (без SUPER-CHIP), экран 64×32 выводится в рамке
по центру текстового режима (пиксель = символ ▀/▄/█ — две строки на знакоместо),
таймеры 60 Гц от системного тика, шестнадцатеричная клавиатура CHIP-8 на клавишах
`1 2 3 4 / Q W E R / A S D F / Z X C V`, Esc — выход. ROM до 3,5 КБ грузится по адресу 200h.
Пример `BALL.CH8` (прыгающий мяч) лежит в корне образа; fm открывает `.CH8` в `micro`.
## Компилятор iron / язык frasm (apps/iron.asm + apps/ironpp.inc → IRON.FAP)

```
iron SOURCE.ASM OUT.FAP
```

`iron` — многопроходный ассемблер, работающий прямо в Ferrix и выдающий плоский
16-битный образ (как `nasm -f bin`). Язык **frasm** — подмножество синтаксиса NASM,
достаточное, чтобы собрать **любую программу этого репозитория, включая сам iron**
(`iron /SYSTEM/SRC/IRON.ASM /IRON2.FAP` даёт файл, байт в байт равный выходу `nasm`):

- метки `name:` и `name` (без двоеточия), локальные `.name` (привязаны к последней глобальной),
  `name equ выражение`, `org N` (по умолчанию 100h); имена чувствительны к регистру, мнемоники — нет;
- препроцессор: `%include "file"` (ищется рядом с исходником, до 4 файлов), `%define NAME`,
  `%ifdef`/`%ifndef`/`%else`/`%endif`, `%macro name N` … `%endmacro` с параметрами `%1..%9`
  и локальными метками `%%name` (до 24 макросов), директивы в скобках `[cpu 386]` и т.п.;
- секции: `section .text`/`.data` (выравнивание 4) и `section .bss` с `resb`/`resw`/`alignb`
  (после `.bss` — только резервирование, как у `nasm -f bin`); `bits 16`, `cpu` — игнорируются;
- данные: `db`/`dw`/`dd` (числа, `'c'`, `'AB'`, `"строки"` через запятую), `times N …`, `resb/resw N`, `align N`;
- числа `123`, `0x7C`, `7Ch`, `0b101`, `'A'`; выражения `+ - * / << >> & | ^ ( ) -x ~x`, `$`, `$$`,
  метки (в т.ч. объявленные ниже), константы `equ`;
- команды 8086/186: `mov add or adc sbb and sub xor cmp test inc dec push pop pusha popa pushf popf
  xchg lea not neg mul imul div idiv rol ror rcl rcr shl sal shr sar jmp call j<cc> jcxz loop loope loopne
  ret retf iret int int3 in out rep/repe/repne movsb movsw cmpsb cmpsw stosb stosw lodsb lodsw scasb scasw
  clc stc cmc cld std cli sti hlt nop cbw cwd lahf sahf xlat`;
- подмножество 386 (нужно `calc`): регистры `eax..edi` в любых командах (префикс 66h), `imul r, r/m`,
  `imul r, imm`, `movzx`/`movsx`, `cdq`/`cwde`/`pushad`/`popad`. Непосредственные значения — 16-битные
  (для `mov eax, imm` расширяются до 32 бит: нулями, либо знаком при `imm >= 0FF80h`);
- операнды памяти `[bx+si+смещ]`, `[bp+di]`, `[si]`, `[di]`, `[bx]`, `[bp]`, `[метка+2]`,
  сегментные префиксы `[es:...]`/`[cs:...]`, размеры `byte`/`word`, `short`/`near` для переходов,
  `jmp far seg:off`, `call/jmp` через регистр или память.

Кодирование совпадает с NASM (короткие формы для `al/ax`, `disp8`, `83 /ib`, `6B /ib`): как и NASM
с оптимизацией, iron делает столько проходов (до 13), сколько нужно, чтобы все `jmp`/`j<cc>`
стали короткими, где это возможно (`jcc` далеко — `0F 8x rel16`), а передние ссылки получили минимальный размер.
Ошибки печатаются как `FILE:LINE: error: текст`. Ограничения: исходник до 64 КБ (каждый из файлов; в окне gui —
64 КБ суммарно), результат до 16 КБ, 800 символов (имена до 35 знаков), нет `les/lds`, 3-операндного `imul`,
вложенных `%include`, 32-битных констант. Чтобы программа была `.FAP`, начните её с заголовка:

```
    org 0x100
    db "FAPI", 1, 0        ; сигнатура, версия, флаги
    dw start               ; точка входа
    times 8 db 0           ; резерв
start:
    mov si, msg
    mov ah, 2              ; FAPI_PUTS
    int 0x80
    mov ah, 0              ; FAPI_EXIT
    int 0x80
msg db "Hello from frasm!", 13, 10, 0
```

Примеры `TEST.ASM` и `TEST2.ASM` лежат в корне образа: `iron /TEST.ASM /T.FAP`, затем `t`.
Исходники всех программ вместе с `FAPI.INC`/`GAME.INC`/`IRONPP.INC` кладутся в `/SYSTEM/SRC` —
их можно править в `micro`/`fm` и пересобирать прямо в системе: `iron /SYSTEM/SRC/SNAKE.ASM /SNAKE2.FAP`.
## Язык ferpy (tools/fpy.py → frasm → iron)

`ferpy` — компилируемый язык с синтаксисом Python для написания программ под Ferrix. Компилятор
`tools/fpy.py` (Python 3, без зависимостей) переводит `.fpy` в исходник на frasm, который собирает
`iron` прямо в системе (или `nasm -f bin` на хосте — результат побайтно одинаков):

```
python3 tools/fpy.py examples/hello.fpy -o HELLO.ASM     # на хосте
iron /PYHELLO.ASM /HELLO2.FAP                            # в Ferrix (PYHELLO.ASM скопировать в образ: mcopy -i hd.img build/PYHELLO.ASM ::)
hello2 Neo
```

```python
def fizzbuzz(n):
    if n % 15 == 0:
        print("FizzBuzz")
    elif n % 3 == 0:
        print("Fizz")
    elif n % 5 == 0:
        print("Buzz")
    else:
        print(n)

for i in range(1, 21):
    fizzbuzz(i)
```

- Типы: 16-битный `int`, строки (`str`, cp437), байтовые буферы `bytes(N)` и массивы слов
  `array(N)`; статическая проверка типов по первому присваиванию; функции с параметрами и
  аннотациями, рекурсия, локальные переменные на стеке, `global`.
- Операторы и приоритеты как в Python, включая `//` и `%` с округлением вниз, `and`/`or`/`not`
  с коротким замыканием, `if/elif/else`, `while/else`, `for … in range()/else`, `break`,
  `continue`, составные присваивания.
- Около 70 встроенных функций — обёртки над FAPI: `print`/`input`, клавиатура, курсор и атрибуты,
  файлы (`readfile`, `writefile`, `stat`, `chdir`, `shell`, `exec`), время, мышь, `peek/poke`,
  порты, строковые `strcpy/strcat/strcmp/find/upper`, `int()`/`str()`, `vseg()` для прямого
  вывода в видеопамять (работает и в окне `gui`).
- Результат — чистый код 8086 с `int 80h`, без интерпретатора: «пустая» программа 20 байт,
  игра «Жизнь» (`examples/life.fpy`) — 1.1 КБ. Runtime (печать чисел, деление, строки, ввод)
  добавляется только по мере использования.
- Примеры: `examples/{hello,fizzbuzz,primes,guess,strings,life}.fpy`; тест компилятора
  `tests/ferpy_test.fpy` (скомпилировать `fpy.py`, скопировать в образ, затем `iron /PYTEST.ASM /T.FAP`, `t` → 23 проверки `OK`).

Полное описание языка (лексика, типы, области видимости, все встроенные функции, отличия от
Python, устройство генерируемого кода, грамматика) — в **[docs/FERPY.md](docs/FERPY.md)**.
## Файловый менеджер fm (apps/fm.asm → FM.FAP)

```
╔═ /DOCS ══════════════════════════════╗╔═ / ══════════════════════════════════╗
║ .                              <DIR> ║║ DOCS                           <DIR> ║
║ ..                             <DIR> ║║ SYSTEM                         <DIR> ║
║ README.TXT                        18 ║║ BIG24.BMP                     253494 ║
╚══════════════════════════════════════╝╚══════════════════════════════════════╝
 README.TXT    18 bytes                  DOCS
Copied.
 1Help   2Ren    3View   4Edit   5Copy   6Move   7Mkdir  8Del    9New   10Quit
```

`fm` — обычная программа .FAP (ядро её не содержит). Активная панель открывается в текущем каталоге оболочки,
состояние (пути, позиции, активная панель) сохраняется в `/SYSTEM/FM.CFG`, поэтому после `mono`, запуска программы
или перезапуска `fm` возвращается на то же место. Каталоги показываются первыми, всё отсортировано по имени.

| Клавиша | Действие |
|---------|----------|
| Tab | Переключить панель |
| ↑ ↓ PgUp PgDn Home End | Курсор |
| Enter | Войти в каталог (`..` — вверх) / запустить `.FAP` / выполнить `.SH` / открыть по типу: `.BMP` → `view`, `.WAV` → `ferramp`, `.CH8` → `micro`, иначе — показать файл |
| Ins, Space | Пометить / снять пометку (курсор идёт вниз); `+` / `-` — пометить/снять все |
| F1 | Справка по клавишам |
| F2 | Переименовать |
| F3 | Встроенный просмотр (первые 32 КБ файла): ↑ ↓ PgUp PgDn Home, Esc — назад |
| F4 | Редактировать в `mono` (через `exec`: `fm` завершается, запускается `mono`, затем `fm` возвращается) |
| F5 / F6 | Копировать / перенести помеченные (или текущий) в каталог другой панели |
| F7 | Создать каталог |
| F8 | Удалить помеченные (или текущий) с подтверждением |
| F9, Shift+F4 | Создать файл (спрашивается имя) и открыть его в `mono` |
| Ctrl+R | Перечитать каталоги |
| F10, Esc | Выход (оболочка переходит в каталог активной панели) |

Мышь: клик — выбрать запись/панель, двойной клик — Enter, правая кнопка — пометка, клик по нижней строке — F-клавиша.
Файловые операции выполняются командами оболочки через `shell` (`cp`, `mv`, `rm`, `mkdir`, `rename`), поэтому
ограничения общие (`rm` удаляет только пустые каталоги); размер файлов не ограничен — `cp` копирует потоково.
## Графическая оболочка gui (apps/gui.asm → GUI.FAP)

`gui` — рабочий стол и оконный менеджер в текстовом режиме 80×50, целиком в одном файле `GUI.FAP`
(ядро лишь пересылает ему системные вызовы программ — функция `FAPI_WM`, 21h).

```
gui                 обои из /SYSTEM/GUI.CFG (по умолчанию синий тон)
gui -t N            обои-тон N = 0..7 (чёрный, синий, зелёный, бирюзовый, красный, пурпурный, коричневый, серый); запоминается
gui -w FILE.BMP     обои из 8/24-битного BMP (масштабируется до 80×50, цвета подбираются из 16); запоминается
```

- При старте автоматически открывается окно **FM**. Enter на `.FAP` в fm открывает программу в **новом окне**
  (до трёх окон одновременно: сегменты 5000h, 7000h, 8000h). F4 → `mono` в окне, Enter на `.BMP`/`.WAV` →
  `view`/`play` на весь экран (они используют графику/DMA-буферы), после чего рабочий стол восстанавливается.
- Окно: рамка-заголовок с именем, кнопки `[_]` (свернуть — кнопка появляется на панели задач внизу, клик по ней
  разворачивает) и `[x]` (закрыть); перетаскивание мышью за заголовок; окна перекрываются; активное окно —
  с синим заголовком, клик по окну активирует его. Клавиатура всегда идёт в активное окно.
- Закрытие FM (крестик или F10) завершает `gui` и возвращает в обычную консоль 80×25.
- Каждое окно — виртуальный экран 80×25 (сегмент пишется в `[0010h]` программы); все выводящие вызовы
  (`PUTC`, `PUTS`, `PUTAT`, `FILLRECT`, `CLS`, курсор, `SHELL`) перенаправляются в него; координаты мыши
  (`FAPI_MOUSE`) переводятся в систему окна. Программы, пишущие прямо в `B800h`, в окне не видны —
  используйте сегмент из `[0010h]` (так сделано в `mono`, `snake`, `paint`, `calc`).
- `FAPI_SHELL` из окна: на время команды консольный вывод ядра (`print_char`) переключается на виртуальный
  экран окна (`FAPI_WM`, AL=3: CX — сегмент консоли, 0 = B800h), а курсор BIOS ставится в позицию курсора
  программы, поэтому многострочный вывод (`ls`, `cat`…) появляется внутри окна, а не
  поверх рабочего стола; перед запуском команды экран компонуется, чтобы окно успело показать своё состояние.
- Программа, завершаясь после `FAPI_EXEC`, перезапускается с аргументами из своего `seg:0080` (их можно
  поменять перед выходом — так `ferramp` после `.SNG` открывается в том же каталоге без автозапуска).
- «Живой» рабочий стол: окна отбрасывают тень (затемнение клеток справа/снизу), открытие — рамка
  разворачивается из центра, сворачивание — «улетает» к кнопке на панели задач (и обратно при разворачивании),
  закрытие — схлопывается; на панели задач справа идут часы (`FAPI_LOCALTIME`, обновление раз в секунду).
  Анимации тактируются по PIT (`pit_delay`), ~12 кадров по 1/60 с, и рисуются поверх уже
  скомпонованного кадра без окна, поэтому не оставляют мусора.
- Многозадачность кооперативная: переключение происходит на системных вызовах (ожидание клавиши, `KEYHIT`,
  `SLEEP`, `MOUSE`), поэтому программа, крутящая пустой цикл без вызовов, «замораживает» рабочий стол.
## Редактор mono (apps/mono.asm → MONO.FAP)

```
  File   Edit   Search   Help                                         mono 2.0
Hello world
┌─────────────────────────┐
│ New             Ctrl+N  │
│ Open...         Ctrl+O  │
│ Save            Ctrl+S  │
│ Save as...      F2      │
│ Exit            Esc     │
└─────────────────────────┘
 /TEST.TXT *                            Ln 1  Col 12  29 bytes
```

`mono [FILE.TXT]` — полноэкранный редактор с интерфейсом: строка меню (**F10** или щелчок мышью;
стрелки/Enter/Esc), 23 строки текста с горизонтальной прокруткой длинных строк, строка состояния
(имя файла, `*` — есть несохранённые изменения, строка/колонка, размер; сюда же выводятся сообщения),
диалоги в рамке (ввод имени, поиск, замена, вопросы, справка). Без аргумента открывается пустой буфер
(`[untitled]`), имя спросит при сохранении. Щелчок мышью по тексту переставляет курсор.

| Меню | Пункт | Клавиша | Действие |
|------|-------|---------|----------|
| File | New | Ctrl+N | Новый пустой буфер (спросит о сохранении) |
| | Open... | Ctrl+O | Открыть файл по имени |
| | Save | Ctrl+S | Сохранить |
| | Save as... | F2 | Сохранить под другим именем |
| | Exit | Esc | Выход; при изменениях — вопрос `Y` сохранить / `N` не сохранять / `Esc` остаться |
| Edit | Cut line / Copy line / Paste line | Ctrl+X / Ctrl+C / Ctrl+V | Строчный буфер обмена (вставка — перед текущей строкой) |
| | Delete line | Ctrl+Y | Удалить строку |
| | Go to line... | Ctrl+G | Перейти к строке по номеру |
| Search | Find... | Ctrl+F | Поиск (с учётом регистра, по кругу) |
| | Find next | F3 | Следующее вхождение |
| | Replace... | Ctrl+R | Замена: `Y` заменить, `N` пропустить, `A` все остальные, `Esc` стоп; в конце — счётчик |
| Help | Keys / About | F1 | Справка по клавишам / о программе |
| — | — | Стрелки, Home, End, PgUp, PgDn, Ctrl+Home/End | Перемещение (колонка сохраняется), начало/конец текста |
| — | — | Backspace, Delete, Enter, Tab | Удаление, новая строка, 4 пробела |
| — | — | Ctrl+Q | Выйти без сохранения и без вопросов |

Ограничения: до 56 000 байт текста (остаток 64-килобайтного сегмента программы), строка буфера обмена —
до 512 байт, строка поиска/имя файла — до 59 символов. Файл хранится с `CR LF`, внутри редактора — только
`LF`; чтение и запись потоковые (`readat` / `writefile` + `append`). Весь вывод идёт прямо в сегмент
видеопамяти из слова `[0010h]` (в `gui` — виртуальный экран окна), поэтому редактор одинаково работает
в консоли и в окне.
