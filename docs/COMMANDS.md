# Команды оболочки Ferrix OS

Справка встроена: `help` — группы команд (`files`, `system`, `media`, `tools`, `games`, `info`)
с перечнем, `help files` — команды группы с описаниями, `help cat` — синтаксис и
описание одной команды.


### Файлы и каталоги

| Команда | Описание |
|---------|----------|
| `ls [-l] [PATH]`, `dir [-l] [PATH]` | Список каталога в три колонки (имя, размер или `<DIR>`); `-l` — по одному файлу в строке, с длинными именами (LFN) |
| `fm` | Двухпанельный файловый менеджер (см. [APPS.md](APPS.md)) |
| `cd PATH` | Перейти в каталог; `cd ..` — вверх; `cd`, `cd /`, `cd ~` — в корень |
| `pwd` | Показать текущий путь |
| `cat PATH` | Вывести файл |
| `touch PATH` | Создать пустой файл |
| `write PATH текст...` | Записать текст в файл (создать или перезаписать) |
| `mono PATH` | Открыть файл в редакторе |
| `mkdir PATH` | Создать каталог |
| `rename PATH NEWNAME` | Переименовать файл или каталог (в том же каталоге) |
| `cp SRC DST` | Скопировать файл (любого размера, потоково); `DST` — имя, путь или каталог |
| `mv SRC DST` | Перенести/переименовать файл **или каталог** (перенос записи, данные не копируются) |
| `rm PATH` | Удалить файл или **пустой** каталог |

Везде, где написано `PATH`, принимается путь: относительный (`docs/sub/a.txt`, `../b.txt`),
абсолютный (`/docs/a.txt`) или с `~` (корень). Имена — формат 8.3, регистр не важен
(`readme.txt` → `README.TXT`). Длинные имена (LFN) отображаются в `ls`, но создавать
их ядро не умеет — обращаться к таким файлам нужно по короткому имени (`LONGFI~1.TXT`).

Примеры:

```
mkdir docs/notes          # вложенный каталог
cp hello.txt docs/        # копия с тем же именем в docs
mv docs/notes /archive    # перенос каталога в корень под именем ARCHIVE
cat ../readme.txt
ls /
```

### Система

| Команда | Описание |
|---------|----------|
| `fetch` | Информация о системе (neofetch-стиль) |
| `cpu` | Vendor / family / model / stepping / brand string |
| `mem` | Базовая и расширенная память |
| `date`, `time` | Дата и время из RTC |
| `clock` | Часы на весь экран (`CLOCK.FAP`): аналоговый циферблат со стрелками, под ним большие цифры HH:MM:SS и дата (день недели, число, месяц, год); любая клавиша — выход |
| `reboot` | Тёплая перезагрузка |
| `shutdown` | Выключение через APM (если поддерживается) |
| `osinfo`, `credits`, `banner` | Информация об ОС |
| `whoami`, `user` | Показать имя пользователя |
| `user NAME` | Сменить имя (1–16 символов без пробелов) |
| `tz` | Показать часовой пояс и локальное время |
| `tz +7` / `tz -5 utc` | Задать смещение от UTC (−12…+14); `utc` — аппаратные часы (RTC) идут по UTC, и смещение прибавляется к ним (с переносом даты). Без `utc` RTC считается локальным временем |
| `setup` | Повторно запустить мастер первоначальной настройки |
| `saver` | Показать настройку заставки |
| `saver clock 5`, `saver matrix 10`, `saver off` | Заставка (большие часы / «матрица») через N минут бездействия в командной строке (1–99); сохраняется в `USER.CFG` |
| `run FILE.FAP [ARGS]` | Запустить программу (обычно достаточно набрать её имя) |
| `run FILE.SH` | Выполнить скрипт: команды построчно, `#` — комментарий |

При первом запуске (когда нет `USER.CFG`) запускается мастер настройки из четырёх шагов:
имя пользователя → часовой пояс (UTC±H) → что хранят аппаратные часы (1 — локальное время,
как в Windows; 2 — UTC, как в Linux) → заставка и минуты бездействия. Настройки сохраняются в `/SYSTEM/USER.CFG`
(`NAME` / `TZ=+07` / `RTC=LOCAL|UTC` / `SAVER=CLOCK:03`) и применяются к `time`, `date`, `clock`, приветствию и заставке.
Если есть `/SYSTEM/AUTOEXEC.SH`, он выполняется сразу после приветствия.
При последующих запусках система здоровается по времени суток
(`Good evening, neo! Welcome back to Ferrix OS.`). Сброс настройки — `rm /user.cfg`.

### Мультимедиа

| Команда | Описание |
|---------|----------|
| `view PATH.BMP` | Показать картинку (любая клавиша — выход) |
| `play PATH.WAV [sb\|hda]` | Проиграть WAV (любая клавиша — стоп); второй аргумент принудительно выбирает устройство |
| `play PATH.SNG` | Проиграть песню синтезатора: ядро запускает `synth PATH.SNG -p` (играет и выходит) |
| `ferramp [DIR\|FILE]` | Проигрыватель с плейлистом WAV/SNG (FERRAMP.FAP) |
| `synth [FILE.SNG]` | Синтезатор-пианино с секвенсором на HD Audio (SYNTH.FAP) |

**`view`** понимает несжатые BMP с глубиной 8 бит (используется палитра файла),
24 и 32 бита (цвета сводятся к палитре R3-G3-B2). Картинки больше 320×200 уменьшаются
целым шагом (640×400 → 320×200), меньше — центрируются. Файл до ~250 КБ, нужен 386+.
Сохранить подходящий файл: в Paint — «24-разрядный рисунок» или «256-цветный рисунок»;
в GIMP/ImageMagick — `convert photo.jpg -resize 320x200 -colors 256 BMP3:photo.bmp`.

**`play`** проигрывает несжатый WAV (PCM, 8 бит, моно или стерео, 5–45 кГц).
Устройство выбирается автоматически (или принудительно вторым аргументом):

- **Sound Blaster 16** (`sb`, порт 220h, DMA 1) — если найден; так играет QEMU с `-device sb16`.
- **Intel HD Audio** (`hda`) — встроенный звук материнских плат с 2005 года, звук идёт
  в разъём Line Out (зелёный), если такого пина нет — в наушники или динамики.
  Контроллер ищется сканированием PCI (порты CF8h/CFCh, класс 04.03), его регистры
  выше 1 МБ читаются из реального режима через «unreal mode» (FS с 4-ГБ лимитом),
  кодек настраивается командами через Immediate Command Interface: аудиогруппа →
  лучший выходной пин → путь через микшеры к ЦАП, усилители на 0 дБ, EAPD.
  Поток всегда 48 кГц 16 бит стерео (это умеет любой кодек) — 8-битный WAV любой
  частоты пересэмплируется на лету; два буфера по 32 КБ по кольцу, позиция по LPIB.
  Нужен 386+. В QEMU: `-device intel-hda -device hda-output,audiodev=snd0`.

  Перед воспроизведением печатается строка диагностики, например
  `HDA: ctrl 8086:2668 codec 1AF40012 pin 03 dac 02` (контроллер, кодек, выбранный
  пин и ЦАП). Если HDA не инициализировался, `play f.wav hda` покажет этап
  (`HDA init stage X`, расшифровка — в комментарии к `hda_init` в `kernel.asm`).

Файл читается с диска потоково
блоками по 32 КБ в два буфера, поэтому размер ограничен только диском: минута
звука 11 кГц моно занимает ~650 КБ: на дискету помещается около двух минут, на диск 32 МБ — около 50.
Во время игры печатается только заголовок (имя файла, длительность, устройство); любая клавиша
останавливает воспроизведение.

Любую музыку (OGG, MP3, FLAC…) переводит в нужный формат `ffmpeg`:

```bash
ffmpeg -i song.ogg -ac 1 -ar 11025 -acodec pcm_u8 song.wav
mcopy -i hd.img song.wav ::SONG.WAV
```

`-ac 1` — моно, `-ar 11025` — частота (можно 22050 для лучшего качества, файл
вдвое больше), `-acodec pcm_u8` — 8-битный PCM. Декодировать OGG/MP3 на
16-битном ядре нереально, поэтому поддерживается только PCM.

### Утилиты

| Команда | Описание |
|---------|----------|
| `echo текст` | Вывести текст |
| `calc [-g] [EXPR]` | Калькулятор (CALC.FAP): выражения с приоритетами и скобками, 32-битные целые, `0x`-hex; без аргументов — диалог, `-g` — окно с кнопками и мышью |
| `paint [FILE.BMP]` | Рисовалка (PAINT.FAP): холст 80×23, 16 цветов, мышь, сохранение в BMP |
| `iron SRC.ASM OUT.FAP` | Компилятор frasm → `.FAP` прямо в системе (IRON.FAP, см. [APPS.md](APPS.md)) |
| `hex`, `bin` | Перевод десятичного числа в hex / bin |
| `ascii` | Таблица ASCII 32–127 |
| `matrix` | Заставка «матрица»: столбцы из 0 и 1 ходят волнами, как эквалайзер; волны мерцают и случайно сдвигаются (любая клавиша — выход) |
| `clear` | Очистить экран и перерисовать баннер |
| `help [GROUP\|CMD]` | Справка: группы (`files system media tools games info`), список группы или одна команда |

### Игры

| Команда | Описание |
|---------|----------|
| `snake`, `tetris`, `mines`, `2048`, `pong` | Игры из `/SYSTEM/SYSAPPS` (управление — в разделе «Пакет игр») |
| `micro FILE.CH8 [-s N] [-c X] [-q] [-l] [-w]` | Эмулятор CHIP-8 (MICRO.FAP): `micro /BALL.CH8` |

### Горячие клавиши оболочки

- **↑ / ↓** — история команд (последние 8, без дублей подряд)
- **← / →, Home, End** — перемещение по строке; символы вставляются в позицию курсора
- **Tab** — автодополнение: в начале строки — имена команд, дальше — файлы и каталоги текущего (или указанного в пути, `docs/a<Tab>`) каталога. Один вариант дописывается целиком (каталог — с `/`, файл — с пробелом), несколько — до общего префикса, повторный Tab показывает список
- **Backspace / Delete** — удалить символ перед курсором / под курсором
- Неизвестная команда `NAME` → оболочка ищет `NAME.FAP` в текущем каталоге, затем в `/SYSTEM/SYSAPPS`, затем в корне, и запускает её
