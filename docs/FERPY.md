# ferpy — Python-подобный язык для Ferrix OS

`ferpy` — маленький компилируемый язык с синтаксисом Python, предназначенный для написания
программ (`.FAP`) под Ferrix OS. Компилятор `tools/fpy.py` переводит исходник `.fpy` в текст на
**frasm** — ассемблерном диалекте, который понимает встроенный в Ferrix ассемблер `iron`
(и `nasm -f bin`). Никакой виртуальной машины и интерпретатора нет: результат — обычный
16-битный машинный код, который вызывает ядро через `int 80h` (FAPI).

```
┌──────────┐  tools/fpy.py   ┌──────────┐   iron (в Ferrix)    ┌──────────┐
│ prog.fpy │ ──────────────► │ PROG.ASM │ ───────────────────► │ PROG.FAP │
└──────────┘  (Python 3,     └──────────┘   или nasm -f bin    └──────────┘
               на хосте)      frasm                             запуск: prog
```

## 1. Быстрый старт

Файл `hello.fpy`:

```python
print("Hello from ferpy!")
name = args()
if len(name) == 0:
    print("What is your name? ", end="")
    name = input()
print("Hello,", name)
for i in range(1, 6):
    print(i, "*", i, "=", i * i)
```

Компиляция на хосте (нужен только Python 3, без зависимостей):

```
python3 tools/fpy.py hello.fpy              # -> HELLO.ASM рядом с исходником
python3 tools/fpy.py hello.fpy -o out/H.ASM # явное имя результата
```

Результат — текстовый файл frasm (кодировка cp866/cp437, переводы строк CR LF, чтобы его можно
было открыть редактором `mono` прямо в Ferrix). Дальше два пути:

* **в Ferrix**: скопировать `.ASM` на диск Ferrix (`mcopy -i hd.img PYHELLO.ASM ::`; `build.sh` ferpy-примеры
  в образ не кладёт), затем

  ```
  iron /PYHELLO.ASM /HELLO2.FAP
  hello2 Neo
  ```

* **на хосте**: `nasm -f bin HELLO.ASM -o HELLO.FAP` и положить `.FAP` в `/SYSTEM/SYSAPPS` или
  корень образа. Оба ассемблера дают **байт в байт одинаковый** файл.

Программа на ferpy — это обычная `.FAP`: запускается из оболочки по имени, из `fm` по Enter,
работает в окне `gui` (весь вывод идёт через FAPI, поэтому перенаправляется в окно автоматически).

## 2. Лексика

* **Кодировка** исходника — UTF-8. В строковых литералах допустимы только символы, которые есть
  в стандартном шрифте VGA (кодовая страница 437: латиница, цифры, псевдографика `─│┌┐└┘█▓▒░`,
  греческие буквы, `°·√ⁿ²` и т.п.). Кириллица в строках вызывает ошибку компиляции (в Ferrix нет
  русского шрифта); в комментариях — можно что угодно.
* **Комментарии** — от `#` до конца строки.
* **Блоки** выделяются отступами, как в Python. Табуляция считается до следующей кратной 8 позиции.
  Внутри незакрытых скобок `(` `[` перевод строки не значим, поэтому длинные выражения и списки
  аргументов можно переносить.
* **Идентификаторы**: `[A-Za-z_][A-Za-z_0-9]*`, регистр значим. Имена попадают в ассемблерный
  листинг с префиксами (`g_`, `f_`), поэтому не должны быть длиннее ~30 символов (у `iron` лимит
  имени — 35).
* **Ключевые слова**: `def if elif else while for in range break continue return pass global
  and or not True False None`. Имена типов `int str bytes array bool` ключевыми словами не
  являются, но использовать их как имена переменных не стоит.
* **Числа**: десятичные `123`, шестнадцатеричные `0x7C00`, двоичные `0b1010`, подчёркивания для
  читаемости `65_535`. Диапазон литерала — от −32768 до 65535 (всё, что помещается в 16 бит;
  `65535 == -1`).
* **Строки**: в одинарных или двойных кавычках, одна строка исходника. Escape-последовательности:
  `\n \r \t \0 \a \b \e \\ \' \" \xHH`. Обратите внимание: `\n` — это байт 10 (LF); консоль
  Ferrix переводит строку по паре `\r\n`, а `print` сам добавляет `\r\n`, так что явно писать
  переводы строк почти не приходится.
* **Операторы и знаки**: `+ - * / // % & | ^ ~ << >> == != < <= > >= = += -= *= /= //= %= &= |=
  ^= <<= >>= ( ) [ ] , : ->`.

## 3. Типы данных

Все значения — 16-битные машинные слова. Компилятор, тем не менее, различает четыре статических
типа и проверяет их согласованность при компиляции:

| Тип | Что это | Литералы / создание |
|-----|---------|---------------------|
| `int` | знаковое 16-битное целое −32768..32767 (`True`/`False` = 1/0, `None` = 0) | `42`, `-1`, `0xFF`, `True` |
| `str` | адрес ASCIIZ-строки (байты до нуля) в сегменте программы | `"text"`, результат `input()`, `args()`, `str(n)` |
| `bytes` | байтовый буфер фиксированного размера, объявленный на верхнем уровне | `buf = bytes(80)` |
| `array` | массив 16-битных слов фиксированного размера | `a = array(100)` |

* `int` — единственный арифметический тип. Переполнение заворачивается по модулю 2¹⁶ (как в C),
  никаких длинных чисел.
* `str` и `bytes` взаимозаменяемы там, где ожидается строка: `bytes`-буфер, в который записали
  строку с нулём в конце, можно печатать, сравнивать и передавать в функции с параметром `str`.
  Разница только в том, что в `bytes` можно писать по индексу безопасно (строковые литералы
  лежат в секции данных и теоретически тоже изменяемы, но лучше так не делать).
* `array` — массив слов: `a[i]` читает и пишет 16-битное значение. Элементы `bytes`/`str` по
  индексу — беззнаковые байты 0..255.
* Буферы `bytes(N)` и `array(N)` можно создавать **только на верхнем уровне** программы и только с
  константным размером. Память под них резервируется в секции `.bss` и **обнуляется при старте**
  (в момент выполнения строки с объявлением). Буфер нельзя переприсвоить, но его имя можно
  передавать в функции и индексировать откуда угодно.
* Нет: вещественных чисел, списков, словарей, кортежей, объектов, срезов, конкатенации строк
  оператором `+` (см. `strcat`), `len()` у `int`.

Имя переменной привязано к типу в момент первого присваивания; присвоить потом значение другого
типа нельзя:

```python
x = 5
x = "five"        # ошибка: переменная 'x' имеет тип int, присваивается str
```

## 4. Переменные и области видимости

Правила такие же, как в Python, но проще:

* Переменная, которой присваивают значение **на верхнем уровне**, — глобальная. Хранится в секции
  данных (`g_имя dw 0`), т.е. в сегменте программы.
* Переменная, которой присваивают значение **внутри функции**, — локальная (слот на стеке,
  `[bp-2]`, `[bp-4]`…), если имя не объявлено в этой функции через `global`. Параметры функции —
  тоже локальные (`[bp+4]`…).
* Чтение имени, которое в функции не присваивалось, обращается к глобальной переменной.
  Отличие от Python: в Python имя, присвоенное где-либо в функции, локально во всём её теле;
  в ferpy оно становится локальным начиная с первого присваивания (чтение до этого момента —
  глобальное). Чтобы не путаться, объявляйте `global` явно, если функция меняет глобальную
  переменную:

```python
count = 0
def bump():
    global count
    count += 1
```

* Локальные переменные не инициализируются нулём автоматически — читать их до присваивания
  нельзя (компилятор это не отследит, просто получите мусор со стека). Глобальные инициализируются
  той строкой, где они впервые присваиваются (порядок — порядок выполнения программы).
* Переменная цикла `for` — обычная переменная (локальная или глобальная по тем же правилам); после
  цикла она хранит значение границы.
* Буферы `bytes`/`array` — всегда глобальные.
* Вложенных функций, замыканий, классов нет.

## 5. Выражения и операторы

Приоритеты — от низкого к высокому (как в Python):

| Приоритет | Операторы | Примечания |
|-----------|-----------|------------|
| 1 | `or` | короткое замыкание, результат 0/1 |
| 2 | `and` | короткое замыкание, результат 0/1 |
| 3 | `not x` | 0/1 |
| 4 | `== != < <= > >=` | результат 0/1; цепочки `a < b < c` запрещены |
| 5 | `\|` | |
| 6 | `^` | |
| 7 | `&` | |
| 8 | `<< >>` | `>>` арифметический (сохраняет знак), счётчик берётся по модулю 16 |
| 9 | `+ -` | |
| 10 | `* / // % ` | `/` — синоним `//` (целочисленное деление) |
| 11 | `-x ~x +x` | унарные |
| 12 | `f(...)`, `a[i]` | вызов, индексация |

Семантика:

* **Деление и остаток** — как в Python: округление **вниз** и остаток со знаком делителя
  (`-7 // 2 == -4`, `-7 % 3 == 2`, `7 % -3 == -2`). Деление на ноль вызывает исключение
  процессора `#DE`; в Ferrix обработчика нет — программа зависнет/перезагрузится. Проверяйте
  делитель сами.
* **Сравнения** знаковые. `rand()` поэтому специально возвращает 0..32767.
* `and`/`or` возвращают **0 или 1**, а не один из операндов (`0 or 5` в ferpy равно `1`).
* Условие истинно, если значение ≠ 0. Для `str`/`bytes` это означает «адрес не нулевой»,
  т.е. всегда истина — проверяйте `len(s)`.
* `==`/`!=` для двух строк (`str`/`bytes`) сравнивают **содержимое** (вызов `rt_streq`);
  `<`, `>` для строк сравнивают адреса — для лексикографического порядка есть `strcmp`.
* Арифметика указателей: `s + n` для `str`/`bytes`/`array` даёт строку/буфер, сдвинутый на `n`
  **байт** (для `array` — тоже байт, не элементов!). Удобно для «хвоста» строки: `print(s + 2)`.
* Индекс не проверяется на выход за границы. `a[-1]` — слово перед массивом.
* Константы в выражениях вроде `2 + 3` **не** сворачиваются компилятором (кроме операций
  «переменная ∘ константа», которые кодируются одной командой) — пишите константы сразу
  числом, если важен размер кода.

Присваивание — оператор, а не выражение. Поддерживаются `=` и составные `+= -= *= /= //= %= &= |=
^= <<= >>=` (для переменных и элементов). Множественного (`a = b = 0`) и кортежного
(`a, b = b, a`) присваивания нет.

## 6. Операторы управления

```python
if cond:
    ...
elif cond:
    ...
else:
    ...

while cond:
    ...
else:            # выполняется, если цикл закончился не по break
    ...

for i in range(stop):              # 0 .. stop-1
for i in range(start, stop):       # start .. stop-1
for i in range(start, stop, step): # step — ненулевая константа, можно отрицательный
    ...
else:
    ...

break        # выход из ближайшего цикла (else при этом пропускается)
continue     # следующая итерация (в for — с увеличением счётчика)
pass
return [выражение]
```

Особенности `for`:

* `start`/`stop` вычисляются **один раз** перед циклом (как в Python); `stop` сохраняется во
  временной переменной.
* Условие продолжения — `i < stop` при положительном шаге и `i > stop` при отрицательном,
  как у `range`. Если менять `i` внутри тела, это повлияет на цикл (в отличие от Python).
* Итерируется только `range(...)`; `for x in список` нет, потому что нет списков.

Однострочные блоки допустимы: `if x < 0: return 0`.

## 7. Функции

```python
def name(p1, p2: str, p3: array) -> int:
    тело
```

* Параметры по умолчанию имеют тип `int`; аннотации `: int`, `: str`, `: bytes`, `: array`,
  `: bool` задают другой тип (проверяется у вызывающего). Аннотация результата `-> int` (по
  умолчанию), `-> str`, `-> bytes`, `-> array` или `-> None` (функция ничего не возвращает;
  `return` с выражением в ней — ошибка, а использовать её в выражении нельзя).
* Если выполнение доходит до конца тела без `return`, возвращается 0.
* Значений по умолчанию, `*args`, именованных аргументов (кроме `print`) нет.
* Рекурсия поддерживается (глубина ограничена стеком: ~60 КБ минус данные программы).
* Все аргументы передаются через стек слева направо, результат — в `AX`, стек чистит
  вызывающий (соглашение cdecl); так что функции ferpy можно вызывать и из ассемблерных
  вставок, если вы соберёте их вместе с `.ASM` вручную.
* Функции определяются только на верхнем уровне, но вызывать их можно до определения
  (все `def` регистрируются заранее). Переопределить функцию или встроенное имя нельзя.

## 8. Встроенные функции

Почти все встроенные функции — тонкие обёртки над системными вызовами Ferrix (`fapi.inc`),
несколько — небольшие подпрограммы, которые компилятор добавляет в результат только если они
используются (`rt_*`). В таблицах `s` — `str` или `bytes`, `b` — `bytes`, `n` — `int`.

### Ввод/вывод текста

| Функция | Результат | Описание |
|---------|-----------|----------|
| `print(*args, sep=" ", end="\n")` | — | Печатает аргументы (`int` — десятичным числом со знаком, `str`/`bytes` — как строку) через `sep`, затем `end`. `sep`/`end` — только строковые константы; `end="\n"` по умолчанию печатает `\r\n`. `print()` без аргументов — пустая строка |
| `input()` | `str` | Читает строку с клавиатуры (до 80 символов, Backspace работает, Enter завершает, эхо на экран). Возвращает адрес **общего** буфера — следующий `input()` его перезапишет; при необходимости скопируйте `strcpy(buf, input())` |
| `putc(n)` | — | Вывести символ с кодом `n` (FAPI 01) |
| `puts(s)` | — | Вывести строку без перевода строки (FAPI 02) |
| `getkey()` | `int` | Ждать клавишу: младший байт — ASCII (0 или 0xE0 для спецклавиш), старший — скан-код (FAPI 03). `getkey() & 0xFF` — символ, `getkey() >> 8` — скан-код |
| `keyhit()` | `int` | 0, если буфер клавиатуры пуст, иначе код клавиши **без** извлечения (FAPI 04) |
| `kbflush()` | — | Очистить буфер клавиатуры (FAPI 14h) |
| `cls()` | — | Очистить экран (FAPI 07) |
| `setcur(row, col)` | — | Поставить курсор (FAPI 05) |
| `currow()`, `curcol()` | `int` | Положение курсора (FAPI 06) |
| `cursor(on)` | — | Показать (`on` ≠ 0) или спрятать аппаратный курсор (FAPI 10h) |
| `putat(row, col, ch, attr)` | — | Символ с атрибутом в позиции (FAPI 15h). Атрибут — `фон*16 + цвет`, например `0x1F` — белый на синем |
| `putsat(row, col, s, attr)` | — | Строка с атрибутом (FAPI 17h) |
| `fillrect(row, col, h, w, ch, attr)` | — | Залить прямоугольник (FAPI 16h) |
| `beep()` | — | Короткий сигнал (FAPI 13h) |

### Строки и преобразования

| Функция | Результат | Описание |
|---------|-----------|----------|
| `len(s)` | `int` | Длина ASCIIZ-строки (до нуля). Для `array` — число элементов (константа) |
| `sizeof(b)` | `int` | Ёмкость буфера `bytes`/`array` в элементах (константа) |
| `ord(s)` | `int` | Код первого символа; для литерала из одного символа вычисляется при компиляции (`ord("A") == 65`) |
| `str(n)` | `str` | Десятичная запись числа со знаком в общем буфере (перезаписывается следующим `str`/`print` числа) |
| `int(s)` | `int` | Разбор десятичного числа: пробелы в начале пропускаются, допустим знак `-`, разбор до первого нецифрового символа; нет цифр — 0 |
| `strcpy(b, s)` | — | Скопировать строку в буфер (с завершающим нулём) |
| `strcat(b, s)` | — | Дописать строку в конец буфера |
| `strcmp(a, s)` | `int` | −1 / 0 / 1 — лексикографическое сравнение байтов |
| `upper(b)` | — | Перевести латинские буквы буфера в верхний регистр на месте |
| `find(s, n)` | `int` | Индекс первого байта с кодом `n` или −1 |
| `s == t`, `s != t` | `int` | Сравнение содержимого строк (оператор) |

Буферы не проверяют переполнение: `strcat` в `bytes(8)` строки из 20 символов затрёт соседние
данные.

### Числа, время, случайность

| Функция | Результат | Описание |
|---------|-----------|----------|
| `abs(n)`, `min(a, b)`, `max(a, b)` | `int` | Очевидно; `abs(-32768) == -32768` |
| `rand()` | `int` | Псевдослучайное 0..32767 (FAPI 0Fh, обрезано до 15 бит, чтобы быть неотрицательным) |
| `ticks()` | `int` | Младшее слово счётчика таймера BIOS, 18.2 Гц (FAPI 0Ah) |
| `sleep(n)` | — | Пауза `n` тиков (≈ 55 мс каждый; FAPI 0Dh). Внутри `gui` в это время работают другие окна |
| `hour()`, `minute()`, `second()` | `int` | Местное время (FAPI 11h, с учётом часового пояса из `setup`) |

### Файлы и система

| Функция | Результат | Описание |
|---------|-----------|----------|
| `readfile(path, b, max)` | `int` | Прочитать файл целиком в буфер (не больше `max` байт): число прочитанных байт или −1 при ошибке (FAPI 08). Завершающий ноль не добавляется — поставьте `b[n] = 0` сами, если нужна строка. Файлы больше 64 КБ не читаются |
| `writefile(path, b, n)` | `int` | Записать `n` байт в файл (создать/перезаписать): 1 — успех, 0 — ошибка (FAPI 09) |
| `appendfile(path, b, n)` | `int` | Дописать в конец файла (FAPI 1Dh) |
| `stat(path)` | `int` | Размер файла (младшее слово) или −1, если файла нет (FAPI 1Bh) |
| `getcwd(b)` | — | Текущий каталог в буфер (FAPI 0Ch) |
| `chdir(path)` | `int` | Сменить каталог: 1/0 (FAPI 20h) |
| `shell(cmd)` | — | Выполнить команду оболочки Ferrix (`mkdir`, `rm`, `cp`, `echo` …; FAPI 19h). Вывод команды идёт на экран с позиции курсора (в `gui` — одна строка в окно) |
| `exec(cmd)` | — | Отложенный запуск: команда выполнится **после выхода** из программы, после чего программа будет перезапущена с теми же аргументами (так устроен `fm`; FAPI 1Ah) |
| `username(b)` | — | Имя пользователя в буфер (FAPI 12h) |
| `args()` | `str` | Аргументы командной строки одной строкой (без ведущих пробелов; пустая строка, если их нет) |
| `exit()` | — | Немедленно завершить программу (FAPI 00). Конец программы завершает её и без `exit()` |

Пути — как в оболочке: `/DIR/FILE.EXT` или относительно текущего каталога, имена 8.3, регистр не
важен.

| Функция | Результат | Описание |
|---------|-----------|----------|
| `mousex()`, `mousey()` | `int` | Столбец / строка курсора мыши в знакоместах (FAPI 1Eh); в окне `gui` — относительно окна |
| `mousebtn()` | `int` | Кнопки: бит 0 — левая, бит 1 — правая; если мыши нет — 0 |

### Память и порты

| Функция | Результат | Описание |
|---------|-----------|----------|
| `peekb(seg, off)`, `peekw(seg, off)` | `int` | Прочитать байт / слово по физическому адресу `seg:off` |
| `pokeb(seg, off, v)`, `pokew(seg, off, v)` | — | Записать байт / слово |
| `dataseg()` | `int` | Сегмент программы (DS = CS = SS; программа загружена в `4000h`, в окне `gui` — `5000h`/`7000h`/`8000h`) |
| `vseg()` | `int` | Сегмент текстового экрана: `0xB800` в консоли или виртуальный экран окна в `gui` (слово `[0010h]` программы). Пишите туда словами `символ + атрибут*256` по смещению `(row*80+col)*2` — так делает `examples/life.fpy` |

| `outp(port, v)` | — | `out dx, al` |

## 9. Отличия от Python

Коротко о том, чего **нет** и что **не так**:

| Python | ferpy |
|--------|-------|
| Длинные целые, `float`, комплексные | только 16-битный `int` с переполнением |
| `str` неизменяемы, есть `+`, срезы, методы | строки — байтовые буферы; `strcat`, `s + n` сдвигает указатель, методов нет |
| `list`, `dict`, `tuple`, `set`, генераторы | `array(N)`/`bytes(N)` фиксированного размера |
| `for x in iterable` | только `for i in range(...)` |
| Динамическая типизация | статические типы, выводимые из первого присваивания |
| `a and b` возвращает операнд | возвращает 0/1 |
| Цепочки сравнений `a < b < c` | ошибка компиляции |
| Исключения, `try` | нет; ошибки возвращаются значениями (−1, 0) |
| `class`, замыкания, лямбды, декораторы, `import` | нет |
| `print(x, file=…)` и форматирование `f""`, `%` | только `sep`/`end`; формат собирайте из `print(..., end="")` и `str()` |
| `input(prompt)` | `input()` без аргумента — выведите приглашение через `print(..., end="")` |
| Локальная переменная локальна во всей функции | локальна с момента первого присваивания |
| `//`, `%` округляют вниз | **так же**, вниз (специально сделано) |
| `True`/`False` — отдельный тип | это `1`/`0` |
| Строки Unicode | байты cp437 |

## 10. Как устроен сгенерированный код

Полезно знать, если вы читаете `.ASM` или хотите вставлять ассемблерные фрагменты руками.

* **Заголовок** — стандартный `.FAP`: `org 0x100`, сигнатура `"FAPI",1,0`, `dw start`,
  8 байт резерва. Точка входа `start:` выполняет верхний уровень программы по порядку и заканчивается
  `mov ah,0 / int 0x80`.
* **Выражения** вычисляются в `AX` (стековая схема: левый операнд `push ax`, правый — в `AX`,
  затем `mov cx, ax / pop ax` и операция). Если правый операнд — константа, генерируется одна
  команда (`add ax, 5`, `cmp ax, 10`, `shl ax, 3`; умножение на степень двойки — сдвиг).
* **Условия** `if`/`while` компилируются в прямые условные переходы без материализации 0/1;
  `and`/`or`/`not` в условиях — переходами (короткое замыкание).
* **Функции**: `f_имя:` — `push bp / mov bp, sp / sub sp, 2*локальных`; параметры `[bp+4]`
  (последний), `[bp+6]`… (первый — самый дальний); локальные `[bp-2]`, `[bp-4]`…; выход через
  общую метку `f_имя_ret: mov sp, bp / pop bp / ret`. Вызов: `push` аргументов слева направо,
  `call f_имя`, `add sp, 2*n`. Регистры не сохраняются (кроме `BP`, `SP`).
* **Глобальные переменные** — `g_имя dw 0` в `section .data`; строковые литералы — `s_N db …, 0`
  (одинаковые литералы объединяются); буферы — `g_имя resb/resw N` в `section .bss`, обнуляются
  кодом при старте (`rt_zero`), потому что загрузчик `.FAP` не чистит память за концом файла.
* **Runtime** — подпрограммы `rt_divmod`, `rt_itoa`, `rt_print_int`, `rt_strlen`, `rt_streq`,
  `rt_strcmp`, `rt_strcpy`, `rt_strcat`, `rt_upper`, `rt_find`, `rt_atoi`, `rt_input`,
  `rt_skipsp`, `rt_zero` — добавляются только используемые. Все они сохраняют регистры, кроме
  результата.
* **Системные вызовы** — `mov ah, N / int 0x80` с раскладкой регистров из `fapi.inc`.
  Сегментные регистры `DS = ES = CS` программа не меняет (кроме временной смены `ES` в
  `peek`/`poke`).
* Используются только команды 8086 (плюс `imul r16`, `shl r, imm`), так что результат работает
  на любом ПК, где грузится Ferrix.
* Размер: «пустая» программа — 20 байт, `print` числа добавляет ~90 байт runtime,
  `examples/life.fpy` — около 1.1 КБ. Предел `iron` — 16 КБ кода/данных и 800 символов; это
  примерно 1500–2500 строк ferpy.

## 11. Ограничения и советы

* Один исходный файл, без `import`. Общий код приходится копировать — или собирать несколько
  `.ASM` вручную.
* Стек программы — верх 64-килобайтного сегмента, общего с кодом и данными. Глубокая рекурсия
  (тысячи уровней) и большие буферы могут столкнуться; компилятор этого не проверяет.
* Один общий буфер у `input()` и один у `str()`: `print(str(a), str(b))` напечатает `b` дважды.
  Используйте `print(a, b)` — числа печатаются без `str()`.
* Нет проверок границ массивов и переполнения буферов — как в ассемблере.
* Деление на ноль — зависание.
* `keyhit()`+`getkey()` — стандартная пара для игровых циклов; `sleep(1)` отдаёт время другим
  окнам `gui` и не грузит процессор.
* Для скорости рисуйте экран через `vseg()`+`pokew` (прямой доступ к видеопамяти, работает и в
  окне `gui`), а не через `putat` (системный вызов на каждый символ).
* Печать в `gui`: перевод строки `\r\n` обязателен (его добавляет `print`), иначе курсор окна не
  вернётся в начало строки.
* Компилятор ничего не оптимизирует, кроме операций с константами; алгоритмическая сложность — на
  вашей совести, процессор может быть 8088 на 4.77 МГц.
* Имена файлов результата — 8.3 и заглавные (FAT): `fpy.py` сам усекает имя до 8 символов,
  если не задать `-o`.

## 12. Сообщения об ошибках

Формат: `файл:строка: ошибка: текст`. Код возврата 1. Наиболее частые:

| Сообщение | Причина |
|-----------|---------|
| `несогласованный отступ` | отступ блока не совпадает ни с одним открытым уровнем |
| `ожидается 'INDENT'` | после `:` нет блока с отступом |
| `неизвестная переменная 'x'` | чтение имени до присваивания или опечатка |
| `переменная 'x' имеет тип int, присваивается str` | смена типа переменной |
| `оператор + требует int (слева str, справа str)` | конкатенация строк `+` — используйте `strcat` |
| `цепочки сравнений (a < b < c) не поддерживаются` | запишите через `and` |
| `функция f ожидает 2 аргументов, передано 1` | |
| `аргумент 'p' функции f: ожидается str, передан int` | |
| `return: ожидается int, получен str` | тип не совпадает с аннотацией `->` |
| `функция f ничего не возвращает (-> None)` | `return x` в функции с `-> None` или её вызов в выражении |
| `bytes()/array() можно создавать только на верхнем уровне` | |
| `буфер 'b' нельзя переприсвоить` | |
| `шаг range должен быть ненулевой константой` | |
| `число 70000 не помещается в 16 бит` | |
| `символ 'П' нельзя показать стандартным шрифтом VGA (cp437)` | кириллица в строковом литерале |
| `break вне цикла`, `return вне функции`, `global вне функции` | |
| `именованные аргументы допустимы только у print` | |
| `выражение без эффекта` | строка вида `x + 1` без присваивания |
| `вложенные функции не поддерживаются` | `def` внутри `def` |

Ошибки времени выполнения компилятор не ловит; `iron` может дополнительно сообщить о слишком
длинном имени или переполнении лимитов (`FILE:LINE: error: …` с номером строки `.ASM`).

| `life.fpy` | игра «Жизнь»: `vseg()`+`pokew` для быстрого вывода, `keyhit`, `cursor`, `putsat`, вложенные циклы, функции с аннотациями |

Фрагмент `life.fpy`:

```python
def neighbours(x, y) -> int:
    n = 0
    for dy in range(-1, 2):
        for dx in range(-1, 2):
            if dx != 0 or dy != 0:
                xx = (x + dx + W) % W
                yy = (y + dy + H) % H
                n += cells[idx(xx, yy)]
    return n
```

и соответствующий ему (сокращённо) frasm, который порождает компилятор:

```nasm
f_neighbours:
    push bp
    mov bp, sp
    sub sp, 14                  ; n, dy, dx, xx, yy + пределы двух range
    xor ax, ax
    mov [bp-2], ax              ; n = 0
    mov ax, 2
    mov [bp-10], ax             ; предел внешнего range (вычислен один раз)
    mov ax, 65535
    mov [bp-4], ax              ; dy = -1
for_13:
    mov ax, [bp-4]
    cmp ax, [bp-10]
    jge felse_16                ; dy >= 2 -> выход из цикла
    ...
    mov ax, [bp-8]              ; dx
    cmp ax, 0
    je L_24
    jmp L_23                    ; dx != 0 -> тело
L_24:
    mov ax, [bp-4]              ; dy
    cmp ax, 0
    je else_21                  ; оба нули -> пропустить
L_23:
    mov ax, [bp+6]              ; x (первый параметр)
    mov cx, [bp-8]
    add ax, cx                  ; x + dx
    mov cx, [g_W]
    add ax, cx                  ; + W
    mov cx, [g_W]
    call rt_divmod              ; % W (с округлением вниз)
    mov ax, dx
    mov [bp-12], ax             ; xx
    ...
    jmp f_neighbours_ret
```

## 14. Грамматика

```
program     := statement*
statement   := simple NEWLINE | compound
compound    := "def" NAME "(" [param ("," param)*] ")" ["->" type] block
             | "if" expr block ("elif" expr block)* ["else" block]
             | "while" expr block ["else" block]
             | "for" NAME "in" "range" "(" expr ["," expr ["," expr]] ")" block ["else" block]
block       := ":" (simple NEWLINE | NEWLINE INDENT statement+ DEDENT)
param       := NAME [":" type]
type        := "int" | "str" | "bytes" | "array" | "bool" | "None"
simple      := "pass" | "break" | "continue" | "return" [expr]
             | "global" NAME ("," NAME)*
             | target augop expr | target "=" expr | expr
target      := NAME | postfix "[" expr "]"
augop       := "+=" | "-=" | "*=" | "/=" | "//=" | "%=" | "&=" | "|=" | "^=" | "<<=" | ">>="
expr        := or_expr
or_expr     := and_expr ("or" and_expr)*
and_expr    := not_expr ("and" not_expr)*
not_expr    := "not" not_expr | cmp_expr
cmp_expr    := bor_expr [("==" | "!=" | "<" | "<=" | ">" | ">=") bor_expr]
bor_expr    := bxor_expr ("|" bxor_expr)*
bxor_expr   := band_expr ("^" band_expr)*
band_expr   := shift_expr ("&" shift_expr)*
shift_expr  := add_expr (("<<" | ">>") add_expr)*
add_expr    := mul_expr (("+" | "-") mul_expr)*
mul_expr    := unary (("*" | "/" | "//" | "%") unary)*
unary       := ("-" | "~" | "+") unary | postfix
postfix     := atom ( "(" [arg ("," arg)*] ")" | "[" expr "]" )*
arg         := expr | NAME "=" expr          # именованные — только sep/end у print
atom        := NUMBER | STRING | NAME | "True" | "False" | "None" | "(" expr ")"
```
